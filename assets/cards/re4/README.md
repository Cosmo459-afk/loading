# Originales pendientes

Las 14 referencias fueron confirmadas en el chat, pero esos adjuntos inline no están disponibles como archivos en este entorno. No se sustituyen por imágenes generadas ni de otras ediciones.

Guardar aquí cada imagen original con el nombre `imageFile` indicado en `content/collections/re4.json`. Se permite `.jpg`, `.jpeg`, `.png` o `.webp`; modificar `imageFile` si cambia la extensión. El build incorpora los bytes originales en el HTML final, sin depender de un servidor externo. No eliminar marcas o créditos.

Las capturas de inventario se presentan mediante un recorte visual SVG, sin modificar el archivo original. `crop` se expresa en coordenadas de `referenceSize`. Revisar estos encuadres con las imágenes reales antes de entregar.

`npm run build` rechaza la entrega mientras falten originales. `npm run build:preview` genera una previsualización con bloques explícitos «Imagen pendiente» para comprobar el código; no es una entrega al jugador.
